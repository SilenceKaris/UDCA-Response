# Risk Prediction Model for Incomplete UDCA Response

## Overview
This repository contains the deployment code for a prediction model of poor ursodeoxycholic acid (UDCA) response in primary biliary cholangitis (PBC).

## Data Security Statement
⚠️ This repository contains only the prediction model and deployment code; **no patient clinical data are included**.  
The original research data are stored on secure servers at the Shandong Public Health Clinical Center and have been approved by the institutional ethics review board (Approval No.: GWLCZXEC-SOP-K-2025-165).
